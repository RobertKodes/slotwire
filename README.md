# slotwire

Live Solana mainnet as a **Western Union telegraph desk**.

Slot ticks clack the sounder. Fee pressure thickens the click train. Failed txs punch red on the paper tape. Hot programs arrive as short Morse-ish callsigns.

Not an explorer. Not a dashboard. Not a newspaper.

Target live: https://robertkodes.github.io/slotwire/
